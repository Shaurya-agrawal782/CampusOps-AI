## 📊 Slide 3 — The Solution

**Headline:**
## CampusOps AI — One Copilot for All Campus Operations

**Three pillars:**

### 🎯 Issue Triage
Student types their problem in any language.
Gemini classifies, prioritizes, and routes it — in 1.2 seconds.

### 📝 Application Co-pilot
Student says what they need in plain words.
Gemini drafts a complete formal application instantly.

### 🏛️ Admin Command Center
One AI-powered dashboard.
Charts, hotspots, ticket routing, and a live AI situation briefing.

## 📊 Slide 4 — Gemini API Usage

**Headline:**
## Powered by Gemini 1.5 Flash

**Five use cases:**

| # | Usage | What Gemini Returns |
|---|---|---|
| 1 | Issue Classification | Category, Priority, Campus Unit, Sentiment, Summary |
| 2 | Priority Detection | Critical / High / Medium / Low |
| 3 | Multilingual Understanding | Hindi, English, Hinglish → English output |
| 4 | Formal Application Generation | Complete formal letter with subject, body, attachments |
| 5 | Campus Situation Summary | 3-sentence AI briefing for admins |

**Architecture note:**
> Gemini API key is server-side only. Frontend never touches the API directly.
> Fallback keyword classifier handles API failures gracefully.

**Visual suggestion:**
Gemini logo + flow diagram: Student input → Server → Gemini API → Structured JSON → UI.
